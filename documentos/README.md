# Documentos del proyecto

Índice de todo lo que el proyecto entrega, por módulo y por semana. Cada archivo tiene su
enlace directo y su evidencia en el repositorio.

| Módulo / semana | Documento | Formato | Qué contiene |
|---|---|---|---|
| 1. Fundamentos | [Propuesta del módulo 1](modulo1_propuesta.md) | Markdown | Problema y solución en la redacción original, con la tabla de qué se resolvió de cada idea |
| 2. Entrevista | [Entrevista del módulo 2](modulo2_entrevista.md) | Markdown | Las diez necesidades con su cita textual del cliente y las seis preguntas pendientes |
| 3. Requisitos (semana 3) | [Ramos_Betancourt_S3_Requisitos.docx](semana3/Ramos_Betancourt_S3_Requisitos.docx) | Word | Ocho secciones: introducción, actores, necesidades con cita, diez historias con criterios Gherkin, seis requisitos no funcionales, priorización MoSCoW y trazabilidad, uso de IA y preguntas pendientes. Su Anexo es la bitácora de prompts de esa semana |
| 4. Diseño (semana 4) | [Ramos_Michael_S4_Diseno.pdf](semana4/Ramos_Michael_S4_Diseno.pdf) · [Word](semana4/Ramos_Michael_S4_Diseno.docx) | PDF y Word | Siete secciones: contexto y atributos de calidad, alternativas y matriz ponderada, diagramas C4, ADR-001 y ADR-002, modelo de datos, API y uso de IA, más dos anexos |
| 4. Diseño · código de los diagramas | [`semana4/fuentes_mermaid/`](semana4/fuentes_mermaid/) | Mermaid | `contexto.mmd`, `contenedores.mmd` y `modelo_datos.mmd`, que son los mismos tres bloques que aparecen en el documento |
| 5. Pruebas (semana 7) | [`registro_pruebas.md`](../registro_pruebas.md) | Markdown | Reglas de negocio, tabla de casos, decisión de la IA sobre cada caso y revisión final |
| 6. Seguridad (semana 6) | [`revision_seguridad.md`](../revision_seguridad.md) | Markdown | Informe de revisión de código y seguridad: hallazgos, severidad, corrección y estado |
| Todas | [`bitacora_ia.md`](../bitacora_ia.md) | Markdown | Bitácora de uso de IA de las semanas 6, 7 y 8: prompts, decisiones, verificaciones y correcciones |
| Cierre | [`informe_final.md`](../informe_final.md) · [PDF](../informe_final.pdf) | Markdown y PDF | Informe final del proyecto integrador: resumen, problema y usuario, IA en el ciclo de vida, casos de error de la IA, estado final, reflexión ética y legal, aprendizajes y anexos |
